# Python GUI branch

Long-lived branch: `python-gui`. ESP32 sketch: separate `esp32-firmware` branch.

- gui-v1.0.0: original interface.
- gui-v2.0.0: larger preview and redesigned workspace.
- Firmware compatible with both: firmware-v1.0.0.

The README describes the supplied application/protocol. Its historical file
references do not mean firmware code is present on this branch.
Create feature branches from python-gui and open PRs with base python-gui.
Use main for the project overview. Do not merge this component branch into main.
Python CI checks syntax, not hardware behavior or ESP32 compilation.

# GUI changelog

## gui-v2.0.0 — GUI Visibility Update

- Import the supplied redesigned GUI and matching README.
- Larger waveform preview, readable controls, resizable workspace.
- Focus preview, F11/Esc support, preview cycle and scale selection.
- Tabbed settings and separate details/log window.
- Non-GUI Python modules and requirements remain unchanged.
- Same firmware-v1.0.0 and serial protocol as GUI V1.

V2 is a project milestone; it does not indicate a breaking protocol change.

## gui-v1.0.0 — Original GUI

Import the original supplied Python application without application source changes.

Both snapshots predate Git import. No historical commit dates are reconstructed.
Hardware regression remains for the team to perform and document.
